01คำตอบสั้นสามข้อ

อาจารย์นิเทศและหัวหน้าหลักสูตรต้องมีลิงก์สมัครหรือไม่

ไม่ต้อง ผู้ประสานงานเพิ่มชื่ออาจารย์ในชีต Users แถวเดียว

ทุกคนที่มีชื่อในชีต Users เข้าระบบที่หน้าเดียวกัน คือ rmutl.link/sewil โดยกรอกอีเมลแล้วรับลิงก์ทางอีเมล ระบบไม่มีหน้าสมัครเอง เพราะรายชื่อในชีตเป็นด่านกันคนนอก อีเมลที่ไม่มีในชีตจะไม่ได้รับลิงก์

อาจารย์นิเทศใช้บทบาท teacher แล้วเลือกนักศึกษาที่จะดูแลเองในระบบ หัวหน้าหลักสูตรไม่จำเป็นต้องมีบัญชี (ดูหัวข้อ 07)

สถานประกอบการใส่ชื่อและอีเมลตอนไหน

ไม่ได้ใส่เอง นักศึกษาเป็นผู้กรอก

นักศึกษากรอกชื่อ ตำแหน่ง และอีเมลของผู้นิเทศงาน (และที่ปรึกษาร่วมถ้าเป็นคนละคน) ในฟอร์มข้อมูลที่ฝึก ภายใน 13 พ.ย. เมื่อผู้ประสานงานอนุมัติ ระบบส่งอีเมลพร้อมข้อตกลง SE-WIL01 และลิงก์เฉพาะคนไปที่อีเมลนั้น สถานประกอบการใช้ลิงก์นี้ยืนยันข้อตกลงและรับรอง logbook ตลอดภาค โดยไม่ต้องสมัครหรือเข้าระบบ

ใครจับคู่อาจารย์นิเทศ และเมื่อไร

อาจารย์เลือกเองในระบบ ภายใน 14 พ.ย.

อาจารย์ทุกท่านเห็นรายชื่อนักศึกษาทุกคนแบบย่อในแท็บ "จับคู่อาจารย์นิเทศ" กด "รับดูแล" แล้วยืนยัน เมื่อยืนยันแล้ว อาจารย์ท่านอื่นเลือกนักศึกษาคนนั้นไม่ได้ ผู้ที่ยืนยันยกเลิกได้เอง และผู้ประสานงานเปลี่ยนให้ได้

ควรเลือกหลังนักศึกษาส่งข้อมูลที่ฝึก (13 พ.ย.) เพื่อจัดนักศึกษาที่อยู่สถานประกอบการเดียวกันให้อาจารย์คนเดียว และก่อนอนุมัติ ชื่ออาจารย์นิเทศจึงพิมพ์ลงข้อตกลง ถ้ายังไม่มีอาจารย์ก็อนุมัติได้ ข้อตกลงจะพิมพ์ว่า "หลักสูตรจะแจ้งให้ทราบ"

04ข้อมูลของใคร ใครเป็นผู้ใส่

ข้อมูลเข้าระบบได้สามทาง คือ ชีต Users ที่ผู้ประสานงานแก้ ชีต Config (ค่าตั้งระบบ) และฟอร์มของนักศึกษา ไม่มีฝ่ายใดต้องกรอกข้อมูลของตนเองนอกจากนักศึกษา

ข้อมูลผู้ใส่ใส่ที่ไหนเมื่อไร
อีเมล รหัส ชื่อ sec ของนักศึกษาผู้ประสานงานชีต Users บทบาท studentก่อนประกาศให้นักศึกษาเข้าระบบ (9 พ.ย.)
รายชื่ออาจารย์นิเทศผู้ประสานงานชีต Users บทบาท teacherก่อนอาจารย์เลือกนักศึกษา (9–12 พ.ย.)
อาจารย์นิเทศของนักศึกษาแต่ละคนอาจารย์นิเทศ เลือกเอง หรือ ผู้ประสานงาน กำหนดเว็บแอป แท็บ "จับคู่อาจารย์นิเทศ" (ระบบเขียนลงคอลัมน์ advisor_email ให้)ภายใน 14 พ.ย. เปลี่ยนภายหลังได้
ผู้ประสานงานและหัวหน้าหลักสูตรผู้ประสานงานชีต Config: COORDINATOR_* และ PROGRAM_HEAD_*ตั้งไว้แล้ว
สถานประกอบการ ที่อยู่ แผนที่ เว็บไซต์ รูปนักศึกษาฟอร์มข้อมูลที่ฝึก9–13 พ.ย.
ชื่อ ตำแหน่ง อีเมลของผู้นิเทศงานและที่ปรึกษาร่วมนักศึกษาฟอร์มข้อมูลที่ฝึก9–13 พ.ย. นักศึกษาควรแจ้งท่านก่อนกรอก
ตำแหน่งงาน ลักษณะงาน โจทย์ ตารางเวลานักศึกษา ตกลงกับสถานประกอบการฟอร์มข้อมูลที่ฝึก9–13 พ.ย.
การยืนยันข้อตกลงผู้นิเทศงานลิงก์เฉพาะคน (หรือผู้ประสานงานบันทึกว่าลงนามในเอกสาร)ภายใน 16 พ.ย.
การรับรอง logbookผู้นิเทศงานลิงก์เฉพาะคนทุกวันศุกร์ตั้งแต่ 20 พ.ย.
 เบอร์โทรทุกช่องไม่บังคับ ถ้ามีเบอร์นักศึกษาในชีต Users ระบบใช้เติมฟอร์มให้เท่านั้น สถานประกอบการเห็นเฉพาะเบอร์ที่นักศึกษาส่งเอง อ่านการคุ้มครองข้อมูลส่วนบุคคล

05งานของผู้ประสานงาน SE-WIL

ผู้ประสานงาน SE-WIL (บทบาท admin) เป็นผู้ติดต่อหลักของนักศึกษาและสถานประกอบการ และเป็นคนเดียวที่ต้องทำงานทั้งในเว็บแอปและในชีต

  1. เตรียมรายชื่อ

    8–9 พ.ย.
    • ชีต Users: ตั้งคอลัมน์ student_id เป็น Plain text ก่อนวาง แล้วใส่ email (อีเมลมหาวิทยาลัย) role = student student_id name section active = TRUE
    • เพิ่มอาจารย์นิเทศทุกท่าน: email (อีเมลมหาวิทยาลัย) role = teacher name active = TRUE แล้วแจ้งอาจารย์ให้เข้าระบบและเลือกนักศึกษาภายใน 14 พ.ย.
    • ประกาศให้นักศึกษาเข้าที่พอร์ทัลหรือ rmutl.link/sewil และกรอกภายใน 13 พ.ย. แจ้งว่าแถบ "This application was created by a Google Apps Script user" เป็นเรื่องปกติ

  2. ทดลองแต่ละบทบาท (ช่วงทดลองเท่านั้น)

    ก่อนเปิดภาค
    • แท็บ "รีเซ็ตเพื่อทดสอบ" ทำให้นักศึกษา ผู้นิเทศงาน หรืออาจารย์นิเทศทีละคนกลับไปเหมือนเพิ่งเข้าระบบครั้งแรก ดูสิ่งที่จะถูกล้างก่อน และต้องพิมพ์อีเมลยืนยัน
    • ทุกแถวที่ถูกลบหรือแก้เก็บสำเนาไว้ในชีต Trash ไฟล์ย้ายไปถังขยะของ Drive และบันทึกใน Audit เมื่อเริ่มใช้จริงให้ปิดด้วยชีต Config RESET_ENABLED = FALSE

  3. ติดตามการกรอก

    9–13 พ.ย.
    • หน้าภาพรวมในเว็บแอปแสดงสถานะของนักศึกษาทุกคน: ยังไม่กรอก ร่าง ส่งแล้ว ส่งกลับ รอยืนยัน ยืนยันแล้ว

  4. หนังสือแนะนำและแบบตอบรับ SE-WIL00

    9–16 พ.ย.
    • นักศึกษาทุกคนต้องมีแบบตอบรับที่สถานประกอบการลงนาม แม้ฝึกที่เดิม คนที่ยังไม่มีข้อมูลในระบบใช้ฉบับเปล่า คนที่ส่งข้อมูลแล้วพิมพ์ฉบับมีข้อมูลจากหน้าแรกของระบบ บริษัทลงนามอย่างเดียว
    • หน้า 1 ต้องมีลายเซ็นหัวหน้าหลักสูตร ทำได้สองแบบ: แท็บ "เอกสาร" พิมพ์รวมทุกคนครั้งเดียว (ทุกคนที่ส่งข้อมูลแล้ว เฉพาะที่ยังไม่แนบแบบตอบรับ หรือฉบับเปล่ามีชื่อ) ให้ท่านลงนามรวดแล้วนักศึกษามารับ หรือให้นักศึกษาพิมพ์เองแล้วนำไปให้ท่านลงนาม
    • นักศึกษาแนบแบบตอบรับที่ลงนามในระบบภายใน 16 พ.ย. ไม่บังคับก่อนอนุมัติ หน้าภาพรวมแสดง "แบบตอบรับ: แนบแล้ว / ยังไม่แนบ" และมีตัวกรองรายชื่อที่ยังไม่แนบ ข้อมูลที่พิมพ์ส่งไปกับลิงก์และอยู่ในเบราว์เซอร์ของผู้พิมพ์เท่านั้น ไม่เก็บในพอร์ทัล

  5. ดูการจับคู่อาจารย์นิเทศ

    13–14 พ.ย. ก่อนอนุมัติ
    • แท็บ "จับคู่อาจารย์นิเทศ" แสดงว่าใครเลือกใครแล้ว และยังว่างกี่คน รายการ "สิ่งที่ต้องทำ" บนหน้าแรกเตือนเมื่อยังมีนักศึกษาไม่มีอาจารย์
    • กำหนดหรือเปลี่ยนอาจารย์ให้นักศึกษาคนใดก็ได้ด้วยรายการเลือกในคอลัมน์ขวา แล้วกดบันทึก
    • เมื่อจัดเสร็จ ปิดการเลือกเองได้ที่ชีต Config ADVISOR_SELF_ASSIGN = FALSE

  6. ตรวจและอนุมัติ

    ภายใน 14 พ.ย.
    • เปิดรายการที่ "ส่งแล้ว" ตรวจโจทย์ ตารางเวลา ผู้นิเทศงาน แล้วกดอนุมัติ ระบบสร้างข้อตกลง SE-WIL01 เป็น PDF ส่งอีเมลถึงผู้นิเทศงานพร้อมลิงก์เฉพาะคน และส่งสำเนาถึงนักศึกษา
    • ถ้าข้อมูลไม่ครบ กดส่งกลับพร้อมเหตุผล นักศึกษาจะได้อีเมลให้แก้
    • ระบบไม่ยอมให้อนุมัติถ้ายังไม่มีชื่อนักศึกษาในชีต Users เพราะชื่อจะพิมพ์ลงข้อตกลง

  7. ติดตามการยืนยัน

    14–17 พ.ย.
    • รายการที่ยังไม่ยืนยัน กดส่งข้อตกลงซ้ำได้
    • ถ้าสถานประกอบการลงนามในกระดาษแทน กดบันทึกว่าลงนามในเอกสารแล้ว

  8. เสนอคณะแต่งตั้งอาจารย์นิเทศ

    ภายใน 17 พ.ย.
    • ลำดับงาน: นักศึกษาได้แบบตอบรับ → อาจารย์ในหลักสูตรจับคู่เป็นอาจารย์นิเทศและอาจารย์ที่ปรึกษาโครงงาน → ผู้ประสานงานส่งรายชื่ออาจารย์ นักศึกษา และสถานประกอบการเสนอคณะ
    • แท็บ "เอกสาร" (เฉพาะ admin) แสดงจำนวนนักศึกษา สถานประกอบการ อาจารย์นิเทศ และรายชื่อที่ยังไม่มีอาจารย์หรือยังไม่อนุมัติที่ฝึก แล้วกดสร้างบันทึกข้อความขออนุมัติแต่งตั้งอาจารย์นิเทศและอาจารย์ที่ปรึกษาโครงงาน (หัวหน้าหลักสูตรเสนอผ่านหัวหน้าสาขาถึงคณบดี พร้อมบัญชีรายชื่อและสรุปรายอาจารย์) ได้ทั้ง Word และ PDF
    • หัวหน้าหลักสูตรลงนามในบันทึกที่พิมพ์ แล้วส่งธุรการสาขา ธุรการลงเลขที่และวันที่ คณะออกคำสั่งแต่งตั้งเอง เมื่อคณะลงนามคำสั่งแล้ว ใช้ทำงบเบิกค่าเดินทาง และงานพัฒนาทักษะวิชาชีพฯ ออกหนังสือขอเข้านิเทศ
    • ข้อความในเอกสาร (ส่วนราชการ เรียน ผ่าน ชื่อหัวหน้าสาขา ช่วงนิเทศ) แก้ได้ในชีต Config คีย์ที่ขึ้นต้นด้วย DOC_ VISIT และ DEPT_HEAD_NAME

  9. ระหว่างภาค

    18 พ.ย. – 9 มี.ค.
    • ระบบส่งสรุปให้ผู้นิเทศงานทุกวันศุกร์ราว 15:00 น. เอง หน้าภาพรวมแสดงธงเมื่อชั่วโมงต่ำกว่าเป้าหรือมีรายการถูกส่งกลับ
    • เปลี่ยนอาจารย์นิเทศได้ทุกเมื่อในแท็บ "จับคู่อาจารย์นิเทศ" นักศึกษาที่ถอนตัว ตั้ง active = FALSE ในชีต Users

  10. หลังส่งผลการเรียน

    พ้นช่วงอุทธรณ์
    • เมนูในชีต SE-WIL > ลบ CV รูป และเบอร์มือถือนักศึกษา ตามประกาศการคุ้มครองข้อมูลส่วนบุคคล

06อาจารย์นิเทศ: เลือกนักศึกษาเองและสิ่งที่ทำ

เพิ่มอาจารย์ในชีต Users (ผู้ประสานงานทำครั้งเดียว)

เพิ่มแถวของอาจารย์หนึ่งแถว ไม่ต้องแก้แถวของนักศึกษา ตัวอย่าง (ข้อมูลสมมุติ):

emailrolenameactivephone
teacher1@rmutl.ac.thteacherอาจารย์ตัวอย่างTRUE(ไม่บังคับ)
  • ใช้อีเมลมหาวิทยาลัยของอาจารย์ อาจารย์ไม่ต้องมีบัญชี Google
  • คอลัมน์ phone ไม่บังคับ ใส่เฉพาะเบอร์ที่อาจารย์ยินยอม เบอร์จะแสดงให้นักศึกษาและสถานประกอบการที่ตนดูแลเห็น และพิมพ์ลงข้อตกลง

อาจารย์เลือกนักศึกษาเองในแท็บ "จับคู่อาจารย์นิเทศ"

  1. เห็นรายชื่อทุกคนแบบย่อ

    อาจารย์ทุกท่านเห็นนักศึกษาทุกคน: ชื่อ รหัส sec สถานประกอบการ จังหวัด สถานะ และอาจารย์ที่เลือกแล้ว ไม่มีเบอร์โทร CV หรือ logbook จนกว่าจะเป็นอาจารย์นิเทศของคนนั้น

  2. กด "รับดูแล" แล้ว "ยืนยันรับดูแล"

    ยืนยันแล้วนักศึกษาเป็นของท่านทันที ระบบบันทึกว่าใครยืนยันเมื่อไร อาจารย์ท่านอื่นจะเห็นว่า "ยืนยันแล้ว" และเลือกไม่ได้ ถ้าสองท่านกดพร้อมกัน ระบบรับคนแรกและแจ้งอีกท่านว่ามีผู้เลือกแล้ว

  3. ยกเลิกหรือเปลี่ยน

    ผู้ที่ยืนยันกด "ยกเลิก" ได้เอง นักศึกษาจะกลับเป็นว่างให้ท่านอื่นเลือก ผู้ประสานงาน (admin) กำหนดหรือเปลี่ยนให้ใครก็ได้ทุกเมื่อ

  4. ข้อจำกัด

    อาจารย์หนึ่งท่านเลือกเองได้ไม่เกิน 8 คนตามแนวคิดของหลักสูตร (ตั้งได้ที่ ADVISOR_MAX) ผู้ประสานงานกำหนดเกินได้ และปิดการเลือกเองได้เมื่อจัดเสร็จ ถ้าข้อตกลงออกไปแล้ว เปลี่ยนอาจารย์ได้ แต่ชื่อใน PDF ไม่เปลี่ยน

สิ่งที่อาจารย์นิเทศทำ

ในระบบตอนนี้ เปิดแล้ว

  • เลือกนักศึกษาที่จะดูแลในแท็บ "จับคู่อาจารย์นิเทศ"
  • แท็บ "นักศึกษาของฉัน" แสดงเฉพาะนักศึกษาที่ตนดูแล พร้อมรายการสิ่งที่ต้องทำและกำหนดการถัดไปบนหน้าแรก
  • ดูข้อมูลที่ฝึก ข้อตกลง CV รูปและแผนที่สถานประกอบการ เพื่อเตรียมนิเทศ
  • ดูชั่วโมง 305 และ 304 ที่รับรองแล้วและรอรับรอง และรายการที่ผู้นิเทศงานส่งกลับ
  • เห็นผู้ติดต่อของสถานประกอบการ

นอกระบบก่อน แล้วย้ายเข้าระบบ ส่วนที่ 3–6

  • นัดพบนักศึกษาครั้งแรกในสัปดาห์ที่ 1–2 ติดตามคนที่ยังไม่บันทึก logbook
  • พิจารณาข้อเสนอโครงงานในสัปดาห์ที่ 4 (ส่วนที่ 3)
  • นิเทศอย่างน้อย 1 ครั้งและบันทึกการนิเทศ (ส่วนที่ 4)
  • ให้คะแนนตามแบบประเมิน (ส่วนที่ 6)

อาจารย์นิเทศกดอนุมัติข้อมูลที่ฝึกไม่ได้ ถ้าต้องการให้อาจารย์ท่านใดอนุมัติได้ ต้องใช้บทบาท admin ซึ่งเห็นนักศึกษาทุกคน

07หัวหน้าหลักสูตร

หัวหน้าหลักสูตรเป็นผู้ติดต่อกรณีจำเป็น เช่น คำร้องเปลี่ยนหรือยุติการฝึก (SE-WIL02) หรือเมื่อติดต่อผู้ประสานงานไม่ได้ ชื่อและอีเมลอยู่ในชีต Config แล้ว ระบบจึงแสดงในหน้าของนักศึกษาและผู้นิเทศงานโดยไม่ต้องมีบัญชี ข้อตกลง SE-WIL01 พิมพ์ชื่อและอีเมล และมีช่องลงนามของหัวหน้าหลักสูตรสำหรับกรณีที่ลงนามในเอกสาร

ถ้าหัวหน้าหลักสูตรต้องการเข้าดูภาพรวมในระบบ ให้เพิ่มแถวในชีต Users ด้วยบทบาท admin บทบาทนี้เห็นนักศึกษาทุกคนและกดอนุมัติได้ด้วย ระบบยังไม่มีบทบาทที่เห็นทุกคนแบบดูอย่างเดียว จึงควรตกลงกันว่าใครเป็นผู้กดอนุมัติ

08สถานประกอบการ: ผู้นิเทศงานและที่ปรึกษาร่วม

  1. นักศึกษาแจ้งและกรอกข้อมูลให้

    9–13 พ.ย.

    นักศึกษาตกลงตำแหน่งงานและโจทย์กับผู้นิเทศงาน แจ้งว่าจะให้ชื่อและอีเมลแก่หลักสูตร แล้วกรอกในฟอร์ม ถ้าที่ปรึกษาร่วมเป็นคนละคนกับผู้นิเทศงาน นักศึกษากรอกของท่านด้วย

  2. ผู้นิเทศงานได้รับอีเมลจากระบบ

    ทันทีที่ผู้ประสานงานอนุมัติ ภายใน 14 พ.ย.

    อีเมลมีข้อตกลง SE-WIL01 เป็น PDF แนบ ผู้ติดต่อของหลักสูตร (ผู้ประสานงานอยู่บรรทัดแรก) ลิงก์คู่มือผู้นิเทศงาน และปุ่ม "ตรวจและยืนยันข้อตกลง" ซึ่งเป็นลิงก์เฉพาะท่าน ตอบกลับอีเมลนี้จะถึงผู้ประสานงานโดยตรง

  3. ยืนยันข้อตกลง

    ภายใน 16 พ.ย.

    เปิดลิงก์ ติ๊กยอมรับ และพิมพ์ชื่อผู้ยืนยัน หรือลงนามในเอกสารแล้วส่งให้หลักสูตร

  4. รับรอง logbook ทุกสัปดาห์

    ทุกวันศุกร์ตั้งแต่ 20 พ.ย.

    ระบบส่งสรุปรายการที่รอรับรอง ใช้ลิงก์เดิมรับรองหรือส่งกลับพร้อมเหตุผล ลิงก์ใช้ได้ตลอดภาค ถ้าท่านดูแลนักศึกษาหลายคน ลิงก์เดียวเห็นทุกคน

ที่ปรึกษาร่วม (กรณีเป็นคนละคนกับผู้นิเทศงาน) ระบบเตรียมลิงก์ของท่านไว้แล้วตอนอนุมัติ แต่ยังไม่ส่งอีเมล เพราะงานของที่ปรึกษาร่วมเริ่มที่การรับรองโจทย์ในข้อเสนอโครงงานสัปดาห์ที่ 4 อีเมลพร้อมลิงก์จะส่งเมื่อเปิดส่วนที่ 3 ก่อน 2 ธ.ค. ระหว่างนี้ผู้นิเทศงานยืนยันข้อตกลงในนามสถานประกอบการ และข้อตกลงพิมพ์ชื่อที่ปรึกษาร่วมไว้แล้ว

รายละเอียดสำหรับสถานประกอบการอยู่ในคู่มือผู้นิเทศงานและที่ปรึกษาร่วม

09นักศึกษา

  1. เข้าที่พอร์ทัลหรือ rmutl.link/sewil กรอกอีเมลมหาวิทยาลัย แล้วเปิดลิงก์ในอีเมลภายใน 30 นาที ถ้าไม่พบให้ดู Junk
  2. กรอกข้อมูลที่ฝึก ผู้นิเทศงาน ที่ปรึกษาร่วม โจทย์ ตำแหน่งบนแผนที่ แนบ CV และรูป (ไม่บังคับ) แล้วกด "ส่งให้หลักสูตรตรวจ" ภายใน 13 พ.ย.
  3. พิมพ์หนังสือแนะนำและแบบตอบรับ SE-WIL00 (ฉบับมีข้อมูลจากหน้าแรกของระบบหลังกดส่ง หรือฉบับเปล่าถ้ายังไม่มีข้อมูล) ให้หัวหน้าหลักสูตรและสถานประกอบการลงนาม แล้วแนบแบบตอบรับที่ลงนามในระบบภายใน 16 พ.ย. ทุกคน แม้ฝึกที่เดิม
  4. เมื่ออนุมัติ จะได้สำเนาข้อตกลงทางอีเมล และบันทึก logbook ได้ตั้งแต่ 18 พ.ย.
  5. บันทึกทุกวัน แท็ก 305 หรือ 304 ทุกรายการ รายละเอียดอย่างน้อย 30 ตัวอักษร แนบลิงก์ รูป ปัญหา และสิ่งที่ได้เรียนรู้ได้ วันที่ไม่ได้ไปทำงานให้บันทึกเหตุ ชั่วโมงนับเมื่อผู้นิเทศงานรับรองแล้วเท่านั้น เกณฑ์ logbook 15 คะแนน

  • ตารางนักศึกษาทุกคน แยกแท็บ ENGSE305 และ ENGSE304 แต่ละช่องบอกคะแนนและสถานะ: ยังไม่ส่ง ได้แล้ว หรือเลยกำหนด
  • เงื่อนไขผ่านแสดงแยกจากคะแนน เช่น ชั่วโมงที่รับรองแล้วครบ 300 และ 135 ชั่วโมง และมีแบบประเมินจากสถานประกอบการครบ
  • ระดับคะแนนคำนวณจากเกณฑ์ช่วงคะแนนที่ตั้งในชีต Config ให้ตรงกับที่หลักสูตรประกาศ ถ้าแบบประเมินจากสถานประกอบการมาไม่ทัน ระบบเสนอ I ไม่ใช่ F
  • อาจารย์นิเทศตรวจคะแนนของนักศึกษาที่ตนดูแลก่อน แล้วผู้ประสานงานกด "ยืนยันผล" คะแนนจะล็อก และส่งออกเป็นไฟล์สำหรับกรอกในระบบทะเบียนของมหาวิทยาลัย

ปิดภาคและเริ่มภาคใหม่

ระบบใช้ไฟล์ข้อมูลหนึ่งไฟล์ต่อหนึ่งภาค แต่ใช้ URL และลิงก์สั้น rmutl.link/sewil เดิมทุกภาค ขั้นตอนเมื่อจบภาค:

  1. ยืนยันผล

    หลังสอบ ก่อนส่งผลการเรียน

    ล็อกคะแนนและส่งออกไฟล์ผลการเรียน

  2. ปิดภาค

    หลังส่งผลการเรียน

    เมนูในชีต SE-WIL > ปิดภาค: ระบบเปลี่ยนเป็นอ่านอย่างเดียวสำหรับทุกบทบาท แสดงแถบ "ภาคนี้ปิดแล้ว" และหยุดตัวจัดเวลาส่งสรุป

  3. ลบข้อมูลส่วนบุคคล

    พ้นช่วงอุทธรณ์

    เมนูเดิม "ลบ CV รูป และเบอร์มือถือนักศึกษา" ตามประกาศการคุ้มครองข้อมูลส่วนบุคคล

  4. เริ่มภาคใหม่

    ก่อนภาคถัดไป

    เมนูในชีต SE-WIL > เริ่มภาคใหม่: ระบบทำสำเนาไฟล์ข้อมูลทั้งไฟล์เก็บไว้ในโฟลเดอร์ของภาคที่ปิด (เช่น "SE-WIL ฐานข้อมูล 2-2569 ปิดภาค") แล้วล้างข้อมูลรายภาคในไฟล์ที่ใช้งาน ได้แก่ ข้อมูลที่ฝึก logbook ชุดรับรอง ลิงก์ผู้นิเทศงาน และรายชื่อนักศึกษา เก็บค่าตั้งระบบและรายชื่ออาจารย์ไว้ ผู้ประสานงานแก้วันเปิดและปิดภาคในชีต Config แล้วใช้ต่อได้ทันที

12ลำดับการสร้างส่วนที่เหลือ

ส่วนใครใช้พร้อมใช้ระหว่างนี้
1 ทะเบียนที่ฝึกและข้อตกลง เปิดแล้วนักศึกษา ผู้ประสานงาน ผู้นิเทศงาน8 พ.ย. 2569—
2 logbook และการรับรองรายสัปดาห์ เปิดแล้วนักศึกษา ผู้นิเทศงาน อาจารย์นิเทศ (ดู)8 พ.ย. 2569—
คำร้อง SE-WIL02 เปลี่ยนหรือยุติการฝึกระหว่างภาค ยังไม่มีนักศึกษา ผู้ประสานงาน ผู้นิเทศงานเมื่อเกิดเหตุครั้งแรกแบบฟอร์มของหลักสูตร แล้วผู้ประสานงานแก้ข้อมูลในระบบ
3 ข้อเสนอโครงงาน ENGSE304 พร้อมส่งลิงก์ให้ที่ปรึกษาร่วม กำลังทำนักศึกษา อาจารย์นิเทศ ที่ปรึกษาร่วมสัปดาห์ที่ 3 (2 ธ.ค. 2569)ใช้แม่แบบ SE-WIL05 ในหน้าแบบฟอร์ม
4 บันทึกการนิเทศ กำลังทำอาจารย์นิเทศสัปดาห์ที่ 5 (16 ธ.ค. 2569)บันทึกในแบบฟอร์มของหลักสูตร
5 แบบประเมินของผู้นิเทศงานและที่ปรึกษาร่วม กำลังทำผู้นิเทศงาน ที่ปรึกษาร่วมสัปดาห์ที่ 8 (6 ม.ค. 2570)—
6 สรุปคะแนนและระดับคะแนน กำลังทำอาจารย์นิเทศ ผู้ประสานงานสัปดาห์ที่ 14 (17 ก.พ. 2570)—
จับคู่อาจารย์นิเทศ สิ่งที่ต้องทำ และคำแนะนำตามบทบาท เปิดแล้วอาจารย์ ผู้ประสานงาน นักศึกษา ผู้นิเทศงาน8 พ.ย. 2569 (v1.5)—
บันทึกขออนุมัติแต่งตั้งอาจารย์นิเทศ (Word/PDF) เปิดแล้วผู้ประสานงาน9 พ.ย. 2569 (v1.6)—
หนังสือแนะนำและแบบตอบรับ SE-WIL00 ฉบับมีข้อมูล พิมพ์รายคนและพิมพ์รวม แนบแบบตอบรับที่ลงนาม เปิดแล้วนักศึกษา ผู้ประสานงาน อาจารย์นิเทศ9 พ.ย. 2569 (v1.7)—
รีเซ็ตเพื่อทดสอบ นักศึกษา ผู้นิเทศงาน อาจารย์นิเทศ ทีละคน (ปิดได้ด้วย Config) เปิดแล้วผู้ประสานงาน9 พ.ย. 2569 (v1.9)—
logbook: คำแนะนำการแท็ก หลักฐาน (ลิงก์ รูป ปัญหา สิ่งที่ได้เรียนรู้) วันที่ไม่ได้ปฏิบัติงาน และเกณฑ์ 15 คะแนน (SE-WIL04) เปิดแล้วนักศึกษา ผู้นิเทศงาน อาจารย์นิเทศ9 พ.ย. 2569 (v1.8)—

13กรณีที่พบบ่อย

นักศึกษาจะฝึกภาคนี้ที่สถานประกอบการอื่น ไม่ใช่ที่เดิมจาก ENGSE301
ไม่ต้องใช้ SE-WIL02 เพราะยังไม่เริ่มภาค เอกสารคือข้อตกลง SE-WIL01 ฉบับใหม่ของที่ใหม่ ในฟอร์มข้อมูลที่ฝึก นักศึกษาตอบ "ไม่ใช่" ในข้อที่ถามว่าเป็นที่เดิมจาก ENGSE301 หรือไม่ แล้วกรอกเหตุผล ซึ่งระบบบังคับกรอก ที่ใหม่ต้องยืนยันข้อตกลงภายในวันที่ 16 พ.ย. เหมือนทุกคน นักศึกษากลุ่มนี้ควรส่งข้อมูลให้เร็ว และแจ้งสถานประกอบการให้รออีเมลจากระบบ ถ้าที่ใหม่ยืนยันออนไลน์ไม่ได้ ให้ลงนามในเอกสาร แล้วผู้ประสานงานกดบันทึกว่าลงนามในเอกสารแล้ว
ขอเปลี่ยนสถานประกอบการ หรือยุติการฝึกระหว่างภาค
ต้องใช้คำร้อง SE-WIL02 และกรรมการบริหารหลักสูตรอนุมัติ ตามหัวข้อ 09 ของเอกสารแนวคิด ชั่วโมง ENGSE305 ที่รับรองแล้วนับต่อได้ที่แห่งใหม่ ระบบยังไม่มีขั้นตอนนี้ (ดูหัวข้อ 12) ระหว่างนี้ใช้แบบฟอร์มของหลักสูตร แล้วผู้ประสานงานแก้ข้อมูลในระบบตามมติ
อาจารย์เลือกนักศึกษาผิดคน
กด "ยกเลิก" ในแถวนั้น แล้วเลือกคนที่ถูก ถ้าเลือกครบ 8 คนแล้วกดรับเพิ่มไม่ได้ ให้ยกเลิกคนที่ผิดก่อน
อาจารย์เข้าระบบไม่ได้
ตรวจว่ามีแถวในชีต Users บทบาท teacher และอีเมลตรงกับที่อาจารย์พิมพ์ทุกตัวอักษร
นักศึกษาบอกว่าไม่ได้รับอีเมลลิงก์เข้าระบบ
ตรวจว่าอีเมลที่นักศึกษาพิมพ์ตรงกับในชีต Users ทุกตัวอักษร และดู Junk หรือ Quarantine ของ Outlook ระบบให้ขอลิงก์ได้ไม่เกิน 3 ครั้งต่อชั่วโมง ชีต Audit บอกได้ว่าระบบส่งแล้วหรือไม่พบอีเมลนั้น
นักศึกษากรอกอีเมลผู้นิเทศงานผิด
ถ้ายังไม่อนุมัติ กดส่งกลับพร้อมเหตุผลให้นักศึกษาแก้ ถ้าอนุมัติแล้ว แก้อีเมลและชื่อผู้นิเทศงานในชีต Placements แล้วกดส่งข้อตกลงซ้ำ ลิงก์จะไปที่อีเมลใหม่ ส่วน PDF ที่ออกไปแล้วยังพิมพ์ข้อมูลเดิม
สถานประกอบการเปลี่ยนผู้นิเทศงานกลางภาค
ผู้นิเทศงานหรือนักศึกษาแจ้งผู้ประสานงาน แก้ข้อมูลผู้นิเทศงานในชีต Placements รายการที่รอรับรองจะไปที่ผู้นิเทศงานคนใหม่ในรอบวันศุกร์ถัดไป ชั่วโมงที่รับรองแล้วนับต่อ
ลิงก์ของผู้นิเทศงานหลุดไปถึงคนอื่น
ลบค่าในคอลัมน์ token ของท่านในชีต Supervisors ลิงก์เดิมจะใช้ไม่ได้ทันที และระบบออกลิงก์ใหม่ในอีเมลฉบับถัดไป (กดส่งข้อตกลงซ้ำ หรือรอสรุปวันศุกร์)
เปลี่ยนอาจารย์นิเทศระหว่างภาค
อาจารย์คนเดิมกดยกเลิกแล้วให้อาจารย์คนใหม่กดรับดูแล หรือผู้ประสานงานเปลี่ยนให้ในแท็บ "จับคู่อาจารย์นิเทศ" อาจารย์คนใหม่เห็นนักศึกษาทันที อาจารย์คนเดิมจะไม่เห็นรายละเอียดอีก
นักศึกษาถอนรายวิชาหรือยุติการฝึก
ดำเนินการตามคำร้อง SE-WIL02 แล้วตั้ง active = FALSE ในชีต Users ข้อมูลเดิมยังอยู่เป็นหลักฐาน
