# SE-WIL พอร์ทัล ENGSE304–305

พอร์ทัลของรายวิชา ENGSE305 การฝึกเฉพาะตำแหน่ง และ ENGSE304 ปัญหาพิเศษจากสถานประกอบการ ภาคการศึกษาที่ 2/2569
สาขาวิชาวิศวกรรมซอฟต์แวร์ คณะวิศวกรรมศาสตร์ มหาวิทยาลัยเทคโนโลยีราชมงคลล้านนา

เว็บ: https://se-rmutl.github.io/se-wil/

## โครงสร้าง

```
se-wil/
├── index.html              หน้าหลัก: แถบภาค 16 สัปดาห์ ทางเข้าตามบทบาท ประกาศ กำหนดส่ง
├── config.js               ไฟล์ตั้งค่าเดียว: ลิงก์ ประกาศ กำหนดส่ง งานรายสัปดาห์ แบบฟอร์ม ผู้ติดต่อ คำถามพบบ่อย
├── student/                นักศึกษา
│   ├── index.html          สิ่งที่ต้องทำ ขั้นตอนตลอดภาค
│   ├── logbook.html        logbook และการนับชั่วโมง
│   └── project.html        โครงงาน ENGSE304
├── teacher/                อาจารย์
│   ├── index.html          หน้าที่และงานรายสัปดาห์
│   └── supervision.html    การนิเทศและการให้คะแนน
├── company/                สถานประกอบการ
│   ├── index.html          ภาพรวมและสิ่งที่ขอความร่วมมือ
│   └── supervisor.html     คู่มือผู้นิเทศงานและที่ปรึกษาร่วม
├── courses/index.html      รายวิชา สัดส่วนคะแนน เงื่อนไขผ่าน กติกา
├── calendar/index.html     ปฏิทินรายสัปดาห์และกำหนดส่งทั้งหมด
├── forms/index.html        แบบฟอร์ม SE-WIL01–12 และเอกสาร
├── help/index.html         คำถามพบบ่อยและผู้ติดต่อ
├── docs/concept.html       เอกสารแนวคิดการดำเนินงาน (ฉบับร่าง 1.0)
└── assets/
    ├── css/se-wil.css
    ├── js/se-wil.js        ส่วนหัว ส่วนท้าย และส่วนที่คำนวณจากวันที่ (ไม่ต้องแก้)
    └── img/                ตรามหาวิทยาลัย ตราสาขา และภาพประกอบ SVG
```

## งานที่ทำบ่อย (แก้ `config.js` ไฟล์เดียว)

| ต้องการ | แก้ที่ |
|---|---|
| ใส่ลิงก์ระบบ SE-WIL หลัง deploy | `links` รายการ `key: 'sewil'` ช่อง `url` (URL ที่ลงท้ายด้วย `/exec`) |
| ใส่ลิงก์ห้องปฐมนิเทศ กลุ่มสื่อสาร แม่แบบ | `links` ช่อง `url` ของแต่ละรายการ ลิงก์ที่ว่างจะแสดง "เร็ว ๆ นี้" |
| เพิ่มประกาศ | `announcements` เพิ่มรายการใหม่ไว้บนสุด `important: true` แสดงป้าย "สำคัญ" |
| เลื่อนกำหนดส่ง | `deadlines` แก้ `date` (ค.ศ. yyyy-mm-dd) |
| ใส่ชื่ออาจารย์และอีเมล | `contacts` ช่อง `name` และ `email` |
| เปลี่ยนวันเปิดหรือปิดภาค | `term` ทุกหน้าคำนวณสัปดาห์ปัจจุบันใหม่เอง |

`roles` ในแต่ละรายการบอกว่ารายการนั้นแสดงในหน้าของใคร: `student` นักศึกษา, `teacher` อาจารย์, `company` สถานประกอบการ

## ทดสอบวันที่อื่น

เปิดหน้าใดก็ได้แล้วเติม `?today=2027-01-08` ท้าย URL เพื่อดูว่าหน้าเว็บจะแสดงอะไรในวันนั้น

## เปลี่ยนภาพประกอบ

ภาพใน `assets/img/*.svg` เป็นภาพวาดต้นฉบับที่ใช้สีจากตราสัญลักษณ์ ถ้ามีภาพถ่ายนักศึกษาในสถานประกอบการจริง
วางไฟล์ไว้ใน `assets/img/` แล้วเปลี่ยน `src` ของ `<img>` ในหน้านั้น ควรได้รับความยินยอมจากผู้ที่อยู่ในภาพและจากสถานประกอบการก่อนเผยแพร่

## ข้อควรระวัง

repo นี้เป็นสาธารณะ ห้ามใส่ข้อมูลส่วนบุคคลของนักศึกษา รายชื่อสถานประกอบการรายคน หรือลิงก์ที่มีโทเคนลับลงในไฟล์ใด ๆ
ข้อมูลรายคนอยู่ในระบบ SE-WIL (Google Sheets ของหลักสูตร) เท่านั้น
