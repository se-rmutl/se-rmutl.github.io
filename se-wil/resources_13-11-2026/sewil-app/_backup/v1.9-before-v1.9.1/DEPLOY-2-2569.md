## ตัดสินใจก่อนเริ่ม

1. **บัญชีที่ใช้ deploy คือ `dev2solution@gmail.com`** ซึ่งเป็นเจ้าของโฟลเดอร์ Drive "SE-WIL"
   - บัญชีนี้จะเป็นผู้ส่งอีเมลทุกฉบับ เป็นเจ้าของชีตฐานข้อมูล และเป็นเจ้าของไฟล์ข้อตกลง
   - สร้างชีต รัน setup และ deploy ด้วยบัญชีเดียวกันทั้งหมด อย่าสลับบัญชีกลางทาง
2. **โควตาอีเมล:** บัญชี Gmail ส่งได้ประมาณ 100 ผู้รับต่อวัน
   - ขอลิงก์เข้าระบบ 1 ฉบับต่อครั้ง อนุมัติ 1 ราย 2 ฉบับ
   - ถ้านักศึกษาเกิน 30 คน ให้ทยอยอนุมัติวันละไม่เกินประมาณ 30 ราย และดูโควตาที่เมนู SE-WIL > ตรวจโควตาอีเมลวันนี้
3. **ผู้อนุมัติ:** อาจารย์ที่ต้องกดอนุมัติต้องมีบทบาท `admin` ในชีต Users บทบาท `teacher` ดูได้อย่างเดียว
4. **ข้อ 5.3–5.4 ของแม่แบบ SE-WIL01** (ทรัพย์สินทางปัญญาและความลับ) ควรให้นิติกรหรือกรรมการบริหารหลักสูตรดูก่อนอนุมัติรายแรก
5. **CV บังคับหรือไม่:** ค่าเริ่มต้นไม่บังคับ (`CV_REQUIRED` = `FALSE`) เพื่อไม่ให้ติดกำหนด 13 พ.ย. ถ้าต้องการบังคับให้ตั้งเป็น `TRUE` ก่อนประกาศนักศึกษา

## ขั้นตอน

### 1. สร้างชีตในโฟลเดอร์ของรายวิชา (5 นาที)
1. เปิด Chrome ด้วยบัญชี `dev2solution@gmail.com`
2. เปิดโฟลเดอร์ https://drive.google.com/drive/folders/1s63FXDiSsHcWrxTzGkSnyUApR1iE27uF
3. New > Google Sheets ตั้งชื่อ `SE-WIL ฐานข้อมูล 2-2569`
4. คัดลอก ID ของชีตจาก URL (ส่วนระหว่าง `/d/` กับ `/edit`)

### 2. ใส่โค้ด

**ทาง ก: clasp (แนะนำ เพราะส่วนที่ 3–6 จะส่งโค้ดซ้ำได้ด้วยคำสั่งเดียว)**
1. เปิด Apps Script API ของบัญชี dev2solution ที่ https://script.google.com/home/usersettings
2. ในเทอร์มินัล:
   ```bash
   npm install -g @google/clasp
   clasp login                      # เลือกบัญชี dev2solution@gmail.com ในเบราว์เซอร์
   cd ~/class/se/2569/2-69/se-rmutl.github.io/se-wil/resources/sewil-app
   node test/run.js                 # ต้องได้ 434 passed, 0 failed
   mkdir -p deploy && cd deploy
   clasp create --title "SE-WIL 2-2569" --parentId "<ID ของชีต>"
   cp ../src/* .                    # ทับ appsscript.json ที่ clasp สร้าง ด้วยของระบบ
   clasp push -f
   ```
3. เปิดชีตใหม่อีกครั้ง แล้ว Extensions > Apps Script จะเห็นไฟล์ 21 ไฟล์

**ทาง ข: คัดลอกเอง (ไม่ต้องติดตั้งอะไร)**
1. ในชีต เปิด Extensions > Apps Script แล้วตั้งชื่อโปรเจกต์ `SE-WIL 2-2569`
2. Project Settings (รูปเฟือง) > ติ๊ก "Show appsscript.json manifest file in editor"
3. กลับไปที่ Editor แทนเนื้อหา `appsscript.json` ด้วยไฟล์ใน `src/`
4. ลบ `Code.gs` ที่มีมาให้ แล้วสร้างไฟล์ Script ชื่อ `Config` `Logic` `Db` `Auth` `Mail` `Placement` `Agreement` `Files` `Logbook` `Assign` `Todo` `Setup` `Code` `Krut` `Docs` `Letter` `Reset` และไฟล์ HTML ชื่อ `Index` `Styles` `App`
5. คัดลอกเนื้อหาจาก `src/` ไฟล์ชื่อเดียวกันมาวางทีละไฟล์ แล้วกด Save

### 3. ตั้งค่าระบบ (5 นาที)
1. รีเฟรชชีต รอเมนู **SE-WIL** แล้วกด **1) ตั้งค่าระบบ**
2. หน้าขอสิทธิ์ขึ้นคำเตือน "Google hasn't verified this app" ให้กด Advanced > Go to SE-WIL 2-2569 (unsafe) > Allow
3. ตรวจผล
   - ชีต 8 แผ่น: Config, Users, Placements, Supervisors, Logbook, CertBatches, Sessions, Audit
   - ในโฟลเดอร์ SE-WIL มีแม่แบบ "SE-WIL01 แม่แบบข้อตกลง" และโฟลเดอร์ "ข้อตกลง SE-WIL01 2-2569"
   - ชีต Users มีแถว admin ของ dev2solution และของผู้ประสานงาน (thanit@rmutl.ac.th)
4. ชีต **Config**
   - `COORDINATOR_NAME` `COORDINATOR_EMAIL`: ผู้ประสานงาน SE-WIL ค่าเริ่มต้นคือ อาจารย์ธนิต เกตุแก้ว thanit@rmutl.ac.th
   - `COORDINATOR_PHONE`: ไม่บังคับ ใส่เฉพาะเบอร์ที่ยินดีให้นักศึกษาและสถานประกอบการที่เกี่ยวข้องเห็น ควรเป็นเบอร์ที่ทำงาน
   - `PROGRAM_EMAIL`: reply-to ของอีเมลทุกฉบับ ใส่ thanit@rmutl.ac.th หรือเว้นว่างให้ใช้ `COORDINATOR_EMAIL`
   - `PROGRAM_HEAD_NAME` `PROGRAM_HEAD_EMAIL` `PROGRAM_HEAD_PHONE`: หัวหน้าหลักสูตร ผู้ติดต่อกรณีจำเป็น (กรอกก่อนอนุมัติรายแรก เพราะชื่อจะพิมพ์ลงข้อตกลง เบอร์ไม่บังคับและไม่พิมพ์ลงข้อตกลง)
   - ตรวจว่า `PORTAL_URL`, `PLACEMENT_DUE`, `AGREEMENT_DUE`, `ROOT_FOLDER_ID` มีค่าแล้ว

### 4. ตรวจแม่แบบ SE-WIL01
เปิดแม่แบบในโฟลเดอร์ SE-WIL แก้ข้อความได้ แต่ต้องคง `{{...}}` ไว้ทุกช่อง

### 5. Deploy เป็นเว็บแอป (5 นาที)
1. ใน Apps Script: Deploy > New deployment > รูปเฟือง > **Web app**
2. Description: `v1.5` Execute as: **Me (dev2solution@gmail.com)** Who has access: **Anyone**
3. Deploy แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
4. วาง URL ในชีต Config ช่อง `APP_URL`
   - ลิงก์สั้น https://rmutl.link/sewil ใช้ประกาศนักศึกษาและอยู่ในพอร์ทัลแล้ว
   - **ห้ามใส่ลิงก์สั้นใน `APP_URL`** เพราะลิงก์สั้นตัด `?page=...&t=...` ทิ้งตอน redirect (ทดสอบแล้ว 8 พ.ย.) ลิงก์เข้าระบบในอีเมลและลิงก์ผู้นิเทศงานจะใช้ไม่ได้
5. จด URL และ Deployment ID ไว้ในไฟล์ `resources/data/deployment.txt`

### 6. ติดตั้งตัวจัดเวลา
เมนู SE-WIL > **2) ติดตั้งตัวจัดเวลาส่งสรุปรายสัปดาห์** ต้องขึ้นข้อความ "ส่งสรุปทุกวันศุกร์ ประมาณ 15:00 น."

### 7. ทดสอบครบวงจร (20 นาที)
logbook รับเฉพาะวันที่ตั้งแต่วันเปิดภาค จึงต้องเลื่อนวันชั่วคราวระหว่างทดสอบ

1. ชีต Config: ตั้ง `SEMESTER_START` เป็นวันนี้ `2026-11-08` ชั่วคราว
2. ชีต Users เพิ่ม 1 แถวสำหรับนักศึกษาทดสอบ ใช้อีเมลที่**ไม่ใช่** thanit@rmutl.ac.th (อีเมลนั้นเป็น admin) เช่น Gmail ส่วนตัวอีกบัญชี `role` = `student` `student_id` = `TEST-01` `name` = `นักศึกษา ทดสอบ` `advisor_email` = `thanit@rmutl.ac.th` `active` = `TRUE`
   - อีเมลหนึ่งมีได้บทบาทเดียว ถ้าเคยตั้ง thanit@rmutl.ac.th เป็น student ไว้ ให้เปลี่ยนแถวนั้นกลับเป็น `admin` หลังทดสอบ
3. เปิด URL `/exec` ใส่อีเมลนักศึกษาทดสอบ
   - ดูว่าอีเมลลิงก์เข้าระบบไปอยู่ Inbox หรือ Junk ของ Outlook นี่คือสิ่งที่นักศึกษาจะเจอ
4. กรอกข้อมูลที่ฝึก ใส่อีเมล Gmail อีกบัญชีของท่าน (เช่น tkeatkaew@gmail.com) เป็นผู้นิเทศงาน กด "บันทึกร่าง" แล้วแนบ CV (PDF) และรูป จากนั้นกดส่ง
5. เข้าระบบอีกครั้งด้วย dev2solution (admin) แล้วอนุมัติ
   - ไฟล์ Docs และ PDF ต้องอยู่ในโฟลเดอร์ "ข้อตกลง SE-WIL01 2-2569"
   - อีเมลถึงผู้นิเทศงานต้องมี PDF แนบ ข้อความ "กรุณายืนยันภายในวันที่ 16 พฤศจิกายน 2569" และลิงก์คู่มือผู้นิเทศงาน
6. เปิดลิงก์ผู้นิเทศงานจากอีเมล แล้วยืนยันข้อตกลง
   - ในหน้าลิงก์ผู้นิเทศงานกด "เปิด CV" แล้วกดลิงก์ดาวน์โหลด ต้องได้ไฟล์ PDF และเห็นเบอร์ที่กรอกไว้ ลองลบเบอร์นักศึกษาในหน้านักศึกษา แล้วรีเฟรชหน้าผู้นิเทศงาน เบอร์ต้องหายไป
7. กลับไปฝั่งนักศึกษา บันทึก logbook วันนี้ 2 รายการ (305 และ 304) แล้วกด "ส่งให้ผู้นิเทศงานรับรองตอนนี้"
8. เปิดลิงก์ผู้นิเทศงาน รับรอง 1 รายการ ส่งกลับ 1 รายการ แล้วดูว่าฝั่งนักศึกษาเห็นสถานะถูกต้อง
9. เคลียร์ข้อมูลทดสอบ
   - Config: คืน `SEMESTER_START` เป็น `2026-11-18`
   - ลบแถวทดสอบ (เหลือหัวคอลัมน์) ในชีต Placements, Logbook, CertBatches, Supervisors, Sessions และแถว TEST-01 ใน Users (ถ้าแถว TEST-01 เป็น thanit@rmutl.ac.th ให้แก้เป็น `admin` ชื่อ `อาจารย์ธนิต เกตุแก้ว` แทนการลบ)
   - ลบไฟล์ข้อตกลงทดสอบในโฟลเดอร์ข้อตกลง และไฟล์ในโฟลเดอร์ CV กับรูปสถานประกอบการ เลขข้อตกลงจะเริ่ม 001 ใหม่เอง
   - ชีต Audit เก็บไว้ได้

### 8. ใส่รายชื่อจริง (จ. 9 พ.ย.)
1. ชีต Users: เลือกคอลัมน์ `student_id` แล้ว Format > Number > **Plain text** ก่อนวาง
2. วางรายชื่อจาก `resources/data/` (ไฟล์ตัวอย่าง `Users_template.csv`)
   - นักศึกษา: `student`
   - ผู้ประสานงานและผู้ที่อนุมัติ: `admin` (thanit@rmutl.ac.th มีอยู่แล้ว)
   - อาจารย์อื่น: `teacher`
   - คอลัมน์ `phone` ไม่บังคับ ใส่เฉพาะเบอร์อาจารย์ที่เจ้าตัวยินยอม ควรเป็นเบอร์ที่ทำงาน นักศึกษากรอกเบอร์ของตนเองในฟอร์มถ้าต้องการ
   - อาจารย์นิเทศทุกท่าน: `role` = `teacher` ไม่ต้องใส่ `advisor_email` ในแถวนักศึกษา อาจารย์เลือกเองในแท็บ "จับคู่อาจารย์นิเทศ" ภายใน 14 พ.ย.

3. ปุ่ม "เข้าระบบ SE-WIL" ในพอร์ทัลชี้ไปที่ https://rmutl.link/sewil แล้ว (แก้ได้ที่ `se-wil/config.js` รายการ `key: 'sewil'`)

## อัปเกรดจากเวอร์ชันก่อนเป็น v1.5
1. `cp ../src/* .` ในโฟลเดอร์ `deploy/` แล้ว `clasp push -f` (หรือคัดลอกไฟล์ที่เปลี่ยนเอง รวมไฟล์ใหม่ `Files.gs` `Assign.gs` `Todo.gs`)
2. รีเฟรชชีต แล้วกดเมนู SE-WIL > **1) ตั้งค่าระบบ** อีกครั้ง ระบบเพิ่มคอลัมน์และค่า Config ใหม่โดยไม่ลบข้อมูลเดิม (v1.5 เพิ่ม `advisor_set_by` `advisor_set_at` ในชีต Users และ `ADVISOR_SELF_ASSIGN` `ADVISOR_MAX` ใน Config)
3. ถ้ามาจาก v1.3 หรือก่อนหน้า: เมนู SE-WIL > **สร้างแม่แบบ SE-WIL01 ใหม่** แม่แบบเดิมจะเปลี่ยนชื่อขึ้นต้นด้วย [เลิกใช้] (ถ้าแก้ข้อความในแม่แบบเดิมไว้ ต้องแก้ซ้ำในแม่แบบใหม่)
4. Manage deployments > ดินสอ > Version: New version
