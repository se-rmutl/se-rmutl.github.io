ติดตั้ง Docker และตรวจเครื่อง

ทุกคนทำบนเครื่องของตัวเอง ใช้ทั้งงานกลุ่ม งานเดี่ยว และการสอบปฏิบัติ เลือกระบบของเครื่องคุณ แล้วทำตามทีละข้อ จบแล้วรัน check-docker.sh ให้ผ่านทุกข้อ

ใช้เวลา 30–60 นาที ส่วนใหญ่เป็นเวลาดาวน์โหลดพื้นที่ว่าง 20 GB ขึ้นไปRAM 8 GB ขึ้นไป (แนะนำ)

Before you start

ก่อนเริ่ม

Windows 10 หรือ 11 แบบ 64-bitแนะนำ Windows 11 ที่อัปเดตล่าสุด Windows 10 รุ่น 22H2 ยังติดตั้งได้ ถ้าติดตั้งไม่ผ่านให้แจ้งอาจารย์
เปิด virtualizationดูได้ใน Task Manager (ข้อ 1)
สิทธิ์ผู้ดูแลเครื่องต้องเปิด PowerShell แบบ Run as administrator ได้
เทอร์มินัลที่ใช้PowerShell สำหรับ WSL และ Ubuntu สำหรับคำสั่ง docker
macOS รุ่นปัจจุบันหรือย้อนหลังไม่เกิน 2 รุ่นหลัก
รู้ชิปของเครื่องApple silicon (M1, M2, …) หรือ Intel ดูได้ในข้อ 1
รหัสผ่านเครื่องใช้ตอนติดตั้งและตอนเปิด Docker ครั้งแรก
เทอร์มินัลที่ใช้แอป Terminal

Windows · WSL 2

ติดตั้งบน Windows

  1. ตรวจรุ่น Windows และชนิดของเครื่อง

    เปิด Settings › System › About ดูบรรทัด System type ว่าเป็น x64-based (เครื่องส่วนใหญ่) หรือ ARM-based ใช้เลือกตัวติดตั้งในข้อ 4 ถ้า Windows เป็นภาษาไทย เมนูจะเป็นคำไทยในตำแหน่งเดียวกัน

    ตรวจว่าเปิด virtualization แล้ว: กด Ctrl + Shift + Esc เปิด Task Manager › Performance › CPU ต้องเห็น Virtualization: Enabled ถ้าเป็น Disabled ต้องเปิดใน BIOS/UEFI (ดูตารางแก้ปัญหา)

  2. ติดตั้ง WSL 2 และ Ubuntu

    เปิด PowerShell แบบผู้ดูแลระบบ: พิมพ์ powershell ในช่องค้นหาของ Start แล้วเลือก Run as administrator กด Yes เมื่อ Windows ถาม

    พิมพ์ใน PowerShell (Administrator)
    wsl --install

    รอจนติดตั้งเสร็จ แล้ว รีสตาร์ตเครื่อง หลังรีสตาร์ต หน้าต่าง Ubuntu จะเปิดเอง (ถ้าไม่เปิด ให้หา Ubuntu ใน Start) แล้วให้ตั้งชื่อผู้ใช้และรหัสผ่านของ Linux

    ถ้าเคยติดตั้ง WSL มาก่อน ไม่ต้องติดตั้งใหม่ ให้อัปเดตด้วย wsl --update แทน

    ตรวจรุ่นของ WSL ใน PowerShell

    พิมพ์ใน PowerShell
    wsl --version
wsl -l -v
    ผลที่ควรเห็น (ตัวเลขเวอร์ชันอาจต่างกัน)
    WSL version: 2.6.1.0
Kernel version: 6.6.87.2-1
…

  NAME      STATE           VERSION
* Ubuntu    Running         2

    WSL version ต้องเป็น 2.1.5 ขึ้นไป และคอลัมน์ VERSION ของ Ubuntu ต้องเป็น 2 ถ้าเป็น 1 ให้รัน

    พิมพ์ใน PowerShell (เฉพาะเมื่อ VERSION เป็น 1)
    wsl --set-version Ubuntu 2

  3. ถ้าเคยติดตั้ง Docker ใน Ubuntu เอง ให้ถอนออกก่อน

    คนส่วนใหญ่ข้ามข้อนี้ได้ ตรวจในเทอร์มินัล Ubuntu ถ้าไม่มีผลลัพธ์ขึ้นมา ให้ข้ามไปข้อ 4

    พิมพ์ใน Ubuntu
    dpkg -l | grep -E 'docker|containerd'

    ถ้ามีรายการขึ้นมา ให้ถอนออก (แพ็กเกจที่ไม่ได้ติดตั้งจะขึ้นว่าไม่พบ ไม่เป็นไร)

    พิมพ์ใน Ubuntu (วางทั้งก้อนแล้วกด Enter)
    for pkg in docker.io docker-doc docker-compose docker-compose-v2 \
  podman-docker containerd runc docker-ce docker-ce-cli \
  containerd.io docker-buildx-plugin docker-compose-plugin; do
  sudo apt-get remove -y "$pkg"
done

  4. ติดตั้ง Docker Desktop

    1. ดาวน์โหลดจาก หน้าติดตั้ง Docker Desktop for Windows เลือกรุ่นให้ตรงกับข้อ 1 (x86_64 หรือ ARM64) ไฟล์ใหญ่ เริ่มโหลดก่อนได้ ถ้าเน็ตในห้องช้าให้ขอไฟล์จากอาจารย์
    2. ดับเบิลคลิก Docker Desktop Installer.exe ถ้าถามรูปแบบการติดตั้ง ให้เลือกแบบที่แนะนำ (Per-user)
    3. หน้า Configuration เลือก WSL 2 แล้วกด OK (รุ่นเก่าเป็นช่องติ๊ก Use WSL 2 instead of Hyper-V ให้ติ๊กไว้)
    4. ติดตั้งเสร็จ ถ้าขึ้น Close and restart หรือให้ sign out ให้ทำตาม
    5. เปิด Docker Desktop จาก Start กดยอมรับเงื่อนไข ข้ามการ sign in ได้
    6. รอจนมุมล่างซ้ายขึ้น Engine running

  5. เปิด WSL Integration

    ใน Docker Desktop กดรูปเฟือง (Settings) › Resources › WSL integration เปิด Enable integration with my default WSL distro เปิดสวิตช์ Ubuntu แล้วกด Apply & restart

  6. ทดสอบในเทอร์มินัล Ubuntu

    ปิดหน้าต่าง Ubuntu เดิมแล้วเปิดใหม่ จากนั้นรัน

    พิมพ์ใน Ubuntu (ไม่ต้องใส่ sudo)
    docker version
docker run hello-world
    ผลที่ควรเห็น (ตัวเลขเวอร์ชันอาจต่างกัน)
    Client:
 Version:           28.x.x
 …
Server: Docker Desktop 4.xx.x
 Engine:
  Version:          28.x.x
 …

Hello from Docker!
This message shows that your installation appears to be working correctly.

    ต้องเห็นทั้งส่วน Client และ Server และข้อความ Hello from Docker!

    ทำงานในโฟลเดอร์ของ Linux (~/) ไม่ใช่ใน /mnt/c/... ระบบจะเร็วกว่ามากเมื่อรันโปรเจกต์ใน T02

macOS

ติดตั้งบน macOS

  1. ตรวจชิปและรุ่น macOS

    เมนู Apple (มุมซ้ายบน) › About This Mac ถ้าขึ้น Chip Apple M… คือ Apple silicon ถ้าขึ้น Processor … Intel คือ Intel ใช้เลือกตัวติดตั้งในข้อ 3

    หรือดูใน Terminal (เปิดจาก Spotlight: กด ⌘ + Space พิมพ์ Terminal)

    พิมพ์ใน Terminal
    uname -m
sw_vers -productVersion
    ผลที่ควรเห็น (arm64 = Apple silicon · x86_64 = Intel)
    arm64
15.x

  2. (เฉพาะ Apple silicon) ติดตั้ง Rosetta 2

    ช่วยให้เครื่องมือบางตัวที่ทำมาสำหรับ Intel ทำงานได้ ถ้ามีอยู่แล้วคำสั่งจะจบเอง

    พิมพ์ใน Terminal
    softwareupdate --install-rosetta --agree-to-license

  3. ติดตั้ง Docker Desktop

    1. ดาวน์โหลดจาก หน้าติดตั้ง Docker Desktop for Mac เลือก Apple silicon หรือ Intel chip ให้ตรงกับข้อ 1 ถ้าเน็ตในห้องช้าให้ขอไฟล์จากอาจารย์
    2. เปิดไฟล์ Docker.dmg แล้วลาก Docker ไปวางที่โฟลเดอร์ Applications
    3. เปิด Docker จาก Applications ถ้า macOS ถามว่าแน่ใจไหมที่จะเปิดแอปที่ดาวน์โหลดมา ให้กด Open และใส่รหัสผ่านเครื่องเมื่อถูกถาม
    4. กดยอมรับเงื่อนไข เลือกการตั้งค่าที่แนะนำ ข้ามการ sign in ได้
    5. รอจนขึ้น Engine running

  4. ทดสอบใน Terminal

    พิมพ์ใน Terminal
    docker version
docker run hello-world
    ผลที่ควรเห็น (ตัวเลขเวอร์ชันอาจต่างกัน)
    Client:
 Version:           28.x.x
 …
Server: Docker Desktop 4.xx.x
 Engine:
  Version:          28.x.x
 …

Hello from Docker!
This message shows that your installation appears to be working correctly.

    ต้องเห็นทั้งส่วน Client และ Server และข้อความ Hello from Docker!

Troubleshooting

ตารางแก้ปัญหา

อาการสาเหตุที่พบบ่อยวิธีแก้
PowerShell ขึ้นว่า wsl --version ไม่รู้จักคำสั่ง หรือ invalid optionWSL รุ่นเก่ามากที่มากับ Windowswsl --update แล้วรันใหม่
Docker Desktop แจ้งว่า WSL ต้องอัปเดต หรือติดตั้งไม่ครบWSL รุ่นเก่าPowerShell: wsl --update แล้วเปิด Docker Desktop ใหม่
แจ้งว่าไม่พบ virtualizationยังไม่เปิดใน BIOS/UEFIรีสตาร์ตเข้า BIOS (มักกด F2, F10 หรือ Del ตอนเปิดเครื่อง) เปิด Intel VT-x หรือ AMD-V (SVM)
wsl -l -v ขึ้น VERSION 1Ubuntu ยังเป็น WSL 1wsl --set-version Ubuntu 2
ใน Ubuntu พิมพ์ docker แล้วไม่พบคำสั่งยังไม่เปิด WSL IntegrationSettings › Resources › WSL integration เปิด Ubuntu แล้วเปิดเทอร์มินัลใหม่
Cannot connect to the Docker daemonDocker Desktop ยังไม่เปิด หรือยังไม่พร้อมเปิด Docker Desktop รอจนขึ้น Engine running
permission denied ที่ docker.sock ใน Ubuntuมี Docker ที่ลงเองใน Ubuntu ค้างอยู่ หรือ integration ยังไม่ทำงานทำข้อ 3 ของ Windows แล้วปิดเปิด Docker Desktop ไม่ต้องใส่ sudo หน้าคำสั่ง docker
curl: command not foundUbuntu ยังไม่มี curlsudo apt update && sudo apt install -y curl
macOS ขึ้นว่า Docker.app is damagedปัญหาการตรวจสอบแอปของ macOSทำตามหัวข้อ Docker.app is damaged ในหน้าติดตั้ง Docker Desktop for Mac
Mac ติดตั้งแล้วเปิดไม่ได้ดาวน์โหลดตัวติดตั้งผิดชิปลบแอปออก แล้วติดตั้งรุ่นที่ตรงกับผล uname -m
ดาวน์โหลดช้ามากหลายคนโหลดพร้อมกันขอไฟล์ติดตั้งจากอาจารย์ หรือโหลดที่บ้านก่อนเข้าคาบ

ไม่มีเครื่องส่วนตัว หรือแก้แล้วยังไม่ผ่าน: ทำแล็บบนเครื่องของเพื่อนในทีมไปก่อน บันทึกข้อความ error ทั้งหมดกับผลจาก check-docker.sh แล้วแจ้งอาจารย์ ในแบบลงทะเบียนให้ตอบตามจริงว่า ยังไม่ผ่าน หรือ ไม่มีเครื่อง
