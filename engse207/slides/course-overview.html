ภาพรวม · 04 · วิธีเรียน

เรียนผ่านระบบเดียว ลงมือทุกครั้ง แล้วค่อยลดตัวช่วย

ระบบเดียวต่อเนื่องทั้งเทอม เชื่อม frontend–API–ฐานข้อมูลในแล็ปเดิม ค่อยลดตัวช่วยก่อนตรวจรายคน เพิ่ม Docker และ Cloud ตรวจข้อเสนอจาก AI อย่างมีหลักฐาน

ภาพรวม · 05 · กรณีศึกษา

ระบบจัดการงานทีม (Task Board) ที่จะพัฒนาไปตลอดเทอม

ทุกทีมได้รับ brief ตั้งแต่ T01 และเริ่มแก้ flow ใน T02 แต่ละครั้งสอนเพิ่มหรือปรับเพียงส่วนเดียวของระบบ ป้าย T บอกครั้งสอนที่เกี่ยวข้อง

ระบบสุดท้ายเป็น modular monolith ได้ ถ้าให้เหตุผลได้
การมี microservices หรือหลายฐานข้อมูลไม่ใช่เงื่อนไขของคะแนนสูง สิ่งที่วัดคือเหตุผลและหลักฐาน
ทุกครั้งสอนต่อยอดจากระบบเดิม
ไม่เริ่มโปรเจกต์ใหม่หลายชุด ผู้สอนเตรียม snapshot สำรองแยกจากงานที่นักศึกษาทำเอง

T01 · ส่วนที่ 1 · ติดตั้ง

ติดตั้ง Docker Desktop บน Windows และ macOS

container ต้องใช้ Linux kernel บน Windows และ macOS จึงมี Linux ทำงานอยู่เบื้องหลัง Windows ใช้ WSL 2 ที่ทุกคนติดตั้งไว้แล้ว

WindowsWSL 2 + Docker Desktopใช้เทอร์มินัล Ubuntu
  1. PowerShell: wsl --version ต้องได้ 2.1.5 ขึ้นไป ถ้าต่ำกว่าให้ wsl --update
  2. wsl -l -v Ubuntu ต้องเป็น VERSION 2
  3. ใครเคยลง Docker ใน Ubuntu เอง ให้ถอนออกก่อน
  4. ติดตั้ง Docker Desktop เลือก Use WSL 2 instead of Hyper-V
  5. Settings › Resources › WSL Integration เปิดสวิตช์ Ubuntu
  6. เปิดเทอร์มินัล Ubuntu แล้วรัน docker run hello-world
macOSDocker Desktopใช้ Terminal
  1. เมนู Apple › About This Mac ดูว่าเป็นชิป Apple M หรือ Intel
  2. ดาวน์โหลดตัวติดตั้งให้ตรงชิป
  3. macOS ต้องเป็นรุ่นปัจจุบัน หรือย้อนหลังไม่เกิน 2 รุ่นหลัก
  4. Apple silicon ให้ลง Rosetta 2: softwareupdate --install-rosetta
  5. ลาก Docker ไปที่ Applications เปิดโปรแกรม รอจนขึ้น Engine running
  6. เปิด Terminal แล้วรัน docker run hello-world

ตรวจผล (ทั้งสองระบบ)

docker version          # ต้องเห็นทั้ง Client และ Server
docker compose version
docker run hello-world  # ต้องเห็น Hello from Docker!

ปัญหาที่พบบ่อย

  • virtualization ปิดใน BIOS → เปิด Intel VT-x หรือ AMD-V
  • Ubuntu ไม่รู้จักคำสั่ง docker → เปิด WSL Integration แล้วเปิดเทอร์มินัลใหม่
  • Cannot connect to the Docker daemon → เปิด Docker Desktop รอ Engine running

T01 · ส่วนที่ 2 · แล็บ Docker

แล็บ C–D: volume และ network

แล็บ Cข้อมูลไม่หายvolume
docker run -d --name db -e POSTGRES_PASSWORD=lab1234 \
  -v pgdata:/var/lib/postgresql/data postgres:17-alpine
# รอ 3–5 วินาทีให้ฐานข้อมูลพร้อม
docker exec -it db psql -U postgres \
  -c "CREATE TABLE tasks(id serial, title text);" \
  -c "INSERT INTO tasks(title) VALUES ('docker');"
docker rm -f db                     # ลบ container ทิ้ง
# รันคำสั่งแรกซ้ำ แล้วตรวจข้อมูล
docker exec -it db psql -U postgres -c "SELECT * FROM tasks;"

ถาม: ถ้าไม่ใส่ -v ข้อมูลยังอยู่ไหม ลองแล้วอธิบายผล

แล็บ Dผู้สอนสาธิตnetwork
docker network create labnet
docker network connect labnet db
docker run --rm -it --network labnet -e PGPASSWORD=lab1234 \
  postgres:17-alpine psql -h db -U postgres -c "SELECT * FROM tasks;"

ถาม: container client รู้จักชื่อ db ได้อย่างไร และถ้าไม่อยู่ใน network เดียวกันจะเกิดอะไรขึ้น

อย่าสับสน C4 Container คือหน่วยซอฟต์แวร์ในแผนภาพ ส่วน Docker container คือหน่วยรันจริง สองคำนี้ไม่ใช่สิ่งเดียวกัน
