แผนเรียนรายสัปดาห์

ก่อนกลางภาคฝึกอ่านระบบและเขียนแบบ หลังกลางภาคนำระบบขึ้นใช้งาน ทดลองทางเลือก แล้วส่งมอบรุ่นที่ตรวจสอบได้ กดเปิดแต่ละสัปดาห์เพื่อดูงานฝึกและสื่อเมื่อเผยแพร่

ก่อนกลางภาค · อ่านและออกแบบระบบ

01ภาพรวมรายวิชาและสถาปัตยกรรม

รู้จักรายวิชา ระบบ Task Board และวิธีประเมิน จัดทีม 3–4 คน แล้วติดตั้ง Docker ให้รัน container แรกได้ ครั้งนี้ยังไม่ใช้โค้ดของระบบ Task Board จะรันครั้งแรกในสัปดาห์ที่ 2

งานและกำหนดส่งสไลด์ภาพรวมรายวิชาใบงาน T01 · Docker

02Client–Server และเส้นทางข้อมูล

ไล่ข้อมูลจาก React ผ่าน API และฐานข้อมูล แล้วแก้กฎตรวจข้อมูลหนึ่งจุดและตรวจผลผ่าน Git diff

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

03คุณลักษณะคุณภาพและการวิเคราะห์ข้อขัดข้อง

เขียนสถานการณ์คุณภาพที่วัดได้ ใช้ Network panel และ log ระบุจุดที่ผิด และตรวจข้อมูลหลังรีสตาร์ต

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

04Layered และ Modular Monolith

แยกหน้าที่ route, service และ repository ในหนึ่ง flow แล้วตรวจว่าพฤติกรรมเดิมยังทำงาน

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

05กรอบแนวคิดและการสื่อสารด้วย C4

วาด Context และ Container จับคู่กล่องกับระบบที่รันจริง และอธิบายหนึ่งเส้นทางสำคัญ

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

06การตัดสินใจและข้อแลกเปลี่ยน

เทียบสองวิธีรองรับกฎการมอบหมายงาน แล้วเขียน ADR บันทึกเหตุผลและผลที่ต้องตรวจ

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

07ทบทวนระบบและจุดตรวจรายบุคคล

อธิบายเส้นทางข้อมูลจากแบบและโค้ด แก้โจทย์ย่อยด้วยตนเอง และทบทวนแบบสถาปัตยกรรมของทีม

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

08สอบกลางภาค

ทบทวนหลักการ รูปแบบสถาปัตยกรรม และการอ่านแผนภาพและการไหลของข้อมูล วันสอบตามประกาศมหาวิทยาลัย

งานและกำหนดส่งขอบเขตและสัดส่วนคะแนน

หลังกลางภาค · ทดลองและส่งมอบ

09Cloud และการนำระบบขึ้นใช้งาน

นำระบบฐานขึ้น Cloud ตรวจการเชื่อมต่อและข้อมูลหลังรีสตาร์ต แล้ววาด Deployment view

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

10สถาปัตยกรรมข้อมูล

ใช้ PostgreSQL เป็นฐาน แล้วทดลอง MongoDB ในส่วนย่อยเพื่อเปรียบเทียบกับรูปแบบข้อมูลและคำค้นจริงของระบบ

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

11การแยกบริการและข้อขัดข้องบางส่วน

ทดลองแยกส่วนงานหนึ่งบริการ สังเกตผลเมื่อบริการหยุด และบันทึกเหตุผลว่าจะคงหรือแยก

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

12Event-Driven Architecture

ทดลองให้หนึ่งเหตุการณ์เรียกงานเบื้องหลัง แล้วสังเกตการตอบสนองและข้อจำกัดเมื่อประมวลผลล่าช้า

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

13การใช้งานบนมือถือและเครือข่ายช้า

ทดลองเว็บเดิมบนหน้าจอเล็กและเครือข่ายช้า ปรับสถานะ loading, error หรือ retry หนึ่งจุด

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

14ประเมินสถาปัตยกรรมด้วยหลักฐาน

เปรียบเทียบสองสถานการณ์ภายใต้เงื่อนไขที่เทียบกันได้ เก็บผลวัดและเลือกหนึ่งจุดที่ควรปรับ

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

15ปรับระบบและเตรียมส่งมอบ

ตรวจว่าคนอื่นเริ่มระบบตาม README ได้ จัดแบบและโค้ดให้ตรงรุ่น และอธิบายส่วนที่ตนมีส่วนร่วม

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

16นำเสนอ ทบทวนกับเพื่อน และต่อยอด

สาธิตการทำงานและข้อแลกเปลี่ยน รับข้อเสนอแนะจากเพื่อน แล้วสะท้อนสิ่งที่จะนำไปใช้กับโครงงาน

งานและกำหนดส่งรายละเอียดสัปดาห์สไลด์จะเผยแพร่ที่นี่

17สอบปลายภาค

ทบทวนการเลือกแบบ อ่านผลทดลอง และแก้โจทย์เล็กบนระบบที่เตรียมไว้ วันสอบตามประกาศมหาวิทยาลัย

งานและกำหนดส่งขอบเขตและสัดส่วนคะแนน

สิ่งที่ทีมจะส่งมอบ

  • แผนภาพสถาปัตยกรรมและบันทึกการตัดสินใจแผนภาพ C4 และ ADR ที่แสดงขอบเขต การติดตั้ง และเหตุผลเบื้องหลังแบบที่เลือก
  • ระบบที่ผู้อื่นเปิดใช้งานตามได้Git repository พร้อม README วิธีเริ่มบนเครื่อง และหลักฐานการนำขึ้น Cloud
  • หลักฐานทดลอง การนำเสนอ และข้อเสนอแนะอธิบายสิ่งที่วัด จุดที่ปรับ และงานที่สมาชิกแต่ละคนรับผิดชอบ
