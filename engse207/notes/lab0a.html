ขั้นที่ 1ติดตั้ง Node.js และ PostgreSQL 30–45 นาที

แอปต้องใช้ 2 อย่าง: Node.js สำหรับรันโค้ด JavaScript ฝั่งเซิร์ฟเวอร์ และ PostgreSQL สำหรับเก็บข้อมูล ใครมี Node.js รุ่น 20 ขึ้นไป และ PostgreSQL รุ่น 14 ขึ้นไปอยู่แล้ว ข้ามไปตรวจรุ่นท้ายขั้นนี้ได้

1.1 macOS

  1. Node.js เปิด nodejs.org ดาวน์โหลดตัวติดตั้งรุ่น LTS (ไฟล์ .pkg) แล้วติดตั้งตามขั้นตอนปกติ
  2. PostgreSQL ใช้ Postgres.app ดาวน์โหลด ลากไปไว้ใน Applications แล้วดับเบิลคลิกเปิด กด Initialize เพื่อสร้างเซิร์ฟเวอร์ (ทำงานที่ localhost พอร์ต 5432)
  3. ให้ Terminal รู้จักคำสั่ง psql ของ Postgres.app แล้ว ปิด Terminal และเปิดใหม่
sudo mkdir -p /etc/paths.d && echo /Applications/Postgres.app/Contents/Versions/latest/bin | sudo tee /etc/paths.d/postgresapp

Postgres.app ต้องเปิดอยู่ (มีรูปช้างที่แถบเมนูด้านบน) ทุกครั้งที่จะใช้ฐานข้อมูล

1.2 Windows (เทอร์มินัล Ubuntu ของ WSL)

sudo apt update
sudo apt install -y postgresql postgresql-client curl                     # ฐานข้อมูล
sudo service postgresql start                                              # เปิดฐานข้อมูล
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -          # เพิ่มแหล่งติดตั้ง Node.js 24
sudo apt install -y nodejs                                                 # Node.js และ npm
  • ทุกครั้งที่ปิดเครื่องหรือปิด WSL แล้วเปิดใหม่ ให้สั่ง sudo service postgresql start อีกครั้ง
  • อย่าใช้ sudo apt install nodejs ก่อน เพิ่มแหล่ง NodeSource เพราะจะได้ Node.js รุ่นเก่าของ Ubuntu
  • เปิดหน้าเว็บที่รันใน WSL ด้วยเบราว์เซอร์ของ Windows ได้ตามปกติ (http://localhost:3000)

3.1 สร้างผู้ใช้และฐานข้อมูล

psql postgres                # macOS (Postgres.app)

CREATE DATABASE taskboard OWNER taskboard;

3.2 สร้างตารางและใส่ข้อมูลตั้งต้น

กลับมาที่โฟลเดอร์ tb-local ตั้งตัวแปรเก็บที่อยู่ฐานข้อมูลไว้ใช้ซ้ำ (ตัวแปรนี้อยู่เฉพาะหน้าต่าง Terminal นี้ เปิดหน้าต่างใหม่ต้องตั้งอีกครั้ง)

cd ~/engse207-practice/tb-local
export DB_URL=postgresql://taskboard:taskboard_dev@localhost:5432/taskboard
psql "$DB_URL" -f db/init/01-schema.sql       # สร้าง 3 ตาราง
psql "$DB_URL" -f db/init/02-seed.sql         # ใส่ข้อมูลตั้งต้น
psql "$DB_URL" -c "\dt"
psql "$DB_URL" -c "SELECT id, title, status, assignee_id FROM tasks ORDER BY id;"
psql "$DB_URL" -c "SELECT COUNT(*) FROM tasks;"
ควรเห็น CREATE TABLE 3 ครั้ง · INSERT 0 4 INSERT 0 1 INSERT 0 7 · \dt มี members projects tasks · งาน 7 แถว งาน #6 ไม่มีผู้รับผิดชอบ · วางผลของ COUNT(*) ในช่องหลักฐาน 2

สังเกตว่าสคริปต์เหล่านี้ ไม่รันเอง เราต้องสั่งรันทีละไฟล์ จำข้อนี้ไว้ ใน Lab 0B จะเห็นว่า Docker รันให้ตอนไหน

6.2 เพิ่ม API ของตัวเอง แล้วแสดงบนหน้าเว็บ

(ก) เซิร์ฟเวอร์ ใน server.js วางโค้ดนี้ เหนือ บรรทัดหัวข้อ “ส่วนที่ 4 · API สมาชิก” เปลี่ยน by เป็นรหัสนักศึกษาของตัวเอง แล้วบันทึก

// Lab 0A · API ที่ฉันเพิ่มเอง
app.get("/api/about", async (req, res) => {
  try {
    const result = await db.query("SELECT COUNT(*)::int AS total FROM tasks");
    res.json({ app: "Task Board", version: "v1-monolith", by: "<รหัสนักศึกษา>", tasks: result.rows[0].total });
  } catch (err) {
    console.error("[api] GET /api/about failed:", err.message);
    res.status(500).json({ error: "เกิดข้อผิดพลาดในระบบ" });
  }
});
curl -s localhost:3000/api/about; echo     # หน้าต่าง Terminal ที่สอง

  2. console.log ใน app.js กับใน server.js ไปโผล่คนละที่ เพราะอะไรแนวคำตอบapp.js ถูกส่งไปรันในเบราว์เซอร์ของผู้ใช้ จึงขึ้นใน Console ของเบราว์เซอร์ ส่วน server.js รันในเครื่องที่เป็นเซิร์ฟเวอร์ จึงขึ้นใน Terminal ที่รันแอป เวลาไล่ปัญหาต้องดูทั้งสองที่
