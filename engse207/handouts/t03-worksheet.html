เปิดระบบไม่ได้ภายใน 10 นาที (อย่าให้ทั้งทีมค้าง)
  • Sign in GitHub ใน VS Code ไม่ผ่าน: ใช้ git clone ใน Terminal และใส่ Personal Access Token แทนรหัสผ่าน หรือให้คนที่ Sign in ได้เป็นผู้ลงมือ

  • พอร์ต 3000 หรือ 5433 ชน: cp .env.example .env แก้ APP_PORT=3001 หรือ DB_HOST_PORT=5434 แล้ว docker compose up -d ใหม่ (RUN.md ส่วน 6)
  • โค้ดใน repo ทีมรันไม่ขึ้น (เช่น แก้ค้างจาก T02): ดึงรุ่น v1-monolith-t03 มาทับตาม RUN.md ส่วน 7 แล้วจดในบันทึกแล็บว่ากู้คืน

การทดลอง · คุณภาพทำอย่างไรทายก่อนผลจริง (ตัวเลข + วิธีวัด)
E1 ฐานข้อมูลหยุด
availability		docker compose stop db รีเฟรชหน้าบอร์ด ดู Network และ health · แล้ว docker compose start db จับเวลาจนบอร์ดกลับมา
E2 deploy ใหม่
availability		ระหว่าง health loop ทำงาน สั่ง docker compose restart app นับบรรทัดที่ไม่ใช่ 200 และช่วงเวลา
E3 รายงานหนัก
performance		ตั้ง REPORT_COST_MS=3000 ใน .env แล้ว docker compose up -d · คนหนึ่งรีเฟรชบอร์ด อีกคนกดสร้างงานทันที · ดูเวลา POST /api/tasks ใน Network เทียบกับ log · เสร็จแล้วตั้งกลับเป็น 0 และ up -d
E4 ขยายระบบ
scalability		docker compose up -d --scale app=2 ดูว่าเกิดอะไร แล้วกลับด้วย --scale app=1
E5 ข้อมูลหลัง restart
reliability		สร้างงาน “ทดสอบ volume” · down แล้ว up -d ดูบอร์ด · จากนั้น down -v แล้ว up -d ดูอีกครั้ง
