# SE-COOP พอร์ทัลสหกิจศึกษา ENGSE300–301

พอร์ทัลของรายวิชา ENGSE301 สหกิจศึกษา (และ ENGSE300 การเตรียมสหกิจศึกษา) สาขาวิชาวิศวกรรมซอฟต์แวร์ คณะวิศวกรรมศาสตร์ มทร.ล้านนา
ภาคการศึกษาที่ 2/2569 นักศึกษารหัส 67 Sec2 (เทียบโอน ปวส.) ปฏิบัติงาน 2 พ.ย. 2569 – 26 ก.พ. 2570

เว็บ: https://se-rmutl.github.io/se-coop/
ระบบ: rmutl.link/secoop (Google Apps Script ซอร์สโค้ดอยู่ใน `resources/secoop-app` บนเครื่องผู้ประสานงาน ไม่ขึ้น git)

พอร์ทัลนี้แยกจาก `se-wil/` (ENGSE304–305) ทั้งไฟล์ ระบบ และข้อมูล คัดลอกโครงมาจาก se-wil แล้วปรับ ไม่ใช้ไฟล์ร่วมกัน
จะรวมเป็นระบบเดียว (v2) หลังปิดภาค 2/2569

## โครงสร้าง

```
se-coop/
├── index.html            หน้าหลัก: แถบการฝึก 17 สัปดาห์ ทางเข้าตามบทบาท ประกาศ กำหนดการ ระบบของคณะกับของหลักสูตร
├── config.js             ไฟล์ตั้งค่าเดียว: ลิงก์ ประกาศ กำหนดการ งานรายช่วง ผู้ติดต่อ คำถามพบบ่อย
├── student/index.html    นักศึกษา: กรอกข้อมูลใน SE-COOP เตรียมรับการนิเทศ งานปลายภาค
├── teacher/index.html    อาจารย์: เลือกนักศึกษา กำหนดวันนิเทศ 2 รอบ เอกสารส่งคณะ การประเมิน S/U
├── company/index.html    สถานประกอบการ: สิ่งที่ขอความร่วมมือ ข้อมูลของท่าน
├── help/index.html       คำถามพบบ่อย ผู้ติดต่อ ประวัติการปรับปรุง
├── help/privacy.html     การคุ้มครองข้อมูลส่วนบุคคล
└── assets/               se-coop.css se-coop.js (คัดลอกจาก se-wil แล้วปรับ) ตราสัญลักษณ์และภาพประกอบ
```

## งานที่ทำบ่อย (แก้ `config.js` ไฟล์เดียว)

| ต้องการ | แก้ที่ |
|---|---|
| ใส่ลิงก์ระบบหลัง deploy | `links` รายการ `key: 'secoop'` ช่อง `url` |
| เพิ่มประกาศ | `announcements` เพิ่มรายการใหม่ไว้บนสุด |
| เลื่อนกำหนดการ | `deadlines` แก้ `date` แล้วแก้ค่าเดียวกันในชีต Config ของระบบ (ชุดทดสอบของระบบตรวจว่าตรงกัน) |
| เปลี่ยนภาค | `term` แถบการฝึกและสัปดาห์ปัจจุบันคำนวณใหม่เอง |

ทดสอบวันที่อื่น: เติม `?today=2026-12-07` ท้าย URL

## ข้อควรระวัง

repo นี้เป็นสาธารณะ ห้ามใส่ชื่อนักศึกษา บริษัทรายคน เบอร์โทร หรือลิงก์ที่มีโทเคนในไฟล์ใด ๆ
ข้อมูลรายคนอยู่ในระบบ SE-COOP (Google Sheets ของหลักสูตร) และ `resources/` ซึ่งอยู่ใน `.gitignore`
