W5-C01 Mental Model

หน้าเดียว แต่มีหลายหน้าได้อย่างไร

แบบเดิม · Multi-Page

กดลิงก์ → เบราว์เซอร์ขอไฟล์ใหม่ → เซิร์ฟเวอร์ส่ง HTML → หน้าจอกะพริบแล้วโหลดใหม่ทั้งหน้า

  • เปลี่ยนหน้าทีต้องคุยกับเซิร์ฟเวอร์ทุกครั้ง
  • ทุกอย่างที่ค้างในหน่วยความจำหายหมด
แบบที่เราใช้ · Single-Page

ขอ index.html ครั้งเดียวตอนเปิดเว็บ หลังจากนั้น Router อ่าน URL แล้วสลับ component ให้

  • ไม่มีการขอไฟล์ HTML ใหม่อีกเลย
  • เปลี่ยนหน้าทันที ไม่กะพริบ
  • แลกกับการที่เราต้องจัดการ URL เอง ← งานวันนี้
พิสูจน์ด้วยตาตัวเอง

เปิด DevTools → แท็บ Network → กดเคลียร์ → กดเปลี่ยนหน้า 3 ครั้ง — ถ้าไม่มีไฟล์ .html ใหม่โผล่ขึ้นมา แปลว่า Router ทำงานถูก

MISCONCEPTION 02 ผมจะเขียนผิดให้ดูอีกรอบ

โค้ดนี้ทำงานได้ — แต่ไม่ควรทำ

const [filtered, setFiltered] = useState([]);

useEffect(() => {
  setFiltered(requests.filter(r => r.status === statusFilter));
}, [requests, statusFilter]);
ปัญหา 3 ข้อ
  • filtered คำนวณได้จากของที่มีอยู่แล้ว ไม่จำเป็นต้องเก็บซ้ำ
  • ทุกครั้งที่ตัวกรองเปลี่ยน หน้าจอวาด 2 รอบ — รอบแรกด้วยค่าเก่า ผู้ใช้อาจเห็นข้อมูลผิดแวบหนึ่ง
  • ที่แย่ที่สุด — ตอนนี้มีข้อมูล 2 ชุดที่ต้องตรงกันตลอด วันไหนลืมทำให้ตรง จะได้หน้าจอผิดโดยไม่มี error ให้จับ
เขียนแบบนี้แทน 
const filtered = statusFilter === 'all'
  ? requests
  : requests.filter(r => r.status === statusFilter);

กฎ — ข้อมูลที่คำนวณได้จาก state ที่มีอยู่แล้ว ให้คำนวณตอนวาดหน้าจอ อย่าเก็บซ้ำ

  // โหลดข้อมูล
}, [scenario]);   ← ทำใหม่เมื่อ scenario เปลี่ยนเท่านั้น

ถ้าใส่ requests ลงไปด้วย ทั้งที่ Effect นี้เป็นคนเซ็ต requests เอง จะเกิดอะไรขึ้น

ทำไมถึงได้ false

optional chaining ป้องกันไม่ให้พังทันที แต่ไม่ได้แปลว่าข้อมูลถูกต้อง — ต้องตรวจชนิดข้อมูลให้ชัดก่อน

const name = typeof input.requesterName === 'string' ? input.requesterName.trim() : '';

fetch() ไม่โยน error เมื่อเซิร์ฟเวอร์ตอบ 404 — มันถือว่าติดต่อสำเร็จแล้ว เพียงแต่ผลลัพธ์คือหน้า error

const response = await fetch(url);
if (!response.ok) throw new Error('ไม่สามารถโหลดข้อมูลตัวอย่างได้');
