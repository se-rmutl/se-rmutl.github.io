สถานะการส่งงานใน repo

ระบบเปิดดู repo ของแต่ละทีมทุกชั่วโมงว่ามีไฟล์ตาม path ที่กำหนดแล้วหรือยัง เลือกรหัสทีมของคุณเพื่อดูว่าขาดอะไร และวางไฟล์ไว้ถูกที่หรือไม่ ถ้าเพิ่ง push กด "ตรวจทีมนี้ใหม่" ได้เลย

กำลังโหลด…

ทุกทีม

แสดงเฉพาะรหัสทีมและสถานะ ไม่มีชื่อ คะแนน หรือเนื้อหาในไฟล์ งานที่ยังไม่ถึงกำหนดแสดงเป็น – จนกว่าทีมจะส่ง · คลิกกระดิ่งในคอลัมน์แจ้งเตือนเพื่อดูว่าทีมต้องทำอะไร

หน้านี้โหลดข้อมูลใหม่เองทุก 5 นาที
  • ✓ ส่งแล้ว ตรงเวลา
  • ✓ ส่งหลังกำหนด
  • ⚠ อยู่ใน branch อื่น ยังไม่ merge
  • – ยังไม่ส่ง ยังไม่ถึงกำหนด
  • ✗ เลยกำหนดแล้วยังไม่ส่ง
  • ? เปิด repo ไม่ได้
  • 2 จำนวนเรื่องที่ทีมต้องทำ คลิกเพื่อดู

ระบบตรวจอะไร

  • ตรวจว่ามีไฟล์หรือโฟลเดอร์ตาม path ในbranch หลักของ repo ชื่อไฟล์และตำแหน่งต้องตรงทุกตัวอักษร ดู path ทั้งหมดที่ path ใน repo
  • เวลาที่แสดงคือเวลา commit แรกที่ไฟล์นั้นเข้ามา ถ้าหลังเวลาครบกำหนด จะขึ้นว่าส่งหลังกำหนด
  • ถ้าพบไฟล์ชื่อคล้ายในที่อื่น ระบบจะบอกให้ย้ายหรือเปลี่ยนชื่อ · งานที่อยู่แค่ใน branch อื่นยังไม่นับจนกว่าจะ merge
  • D01 ผ่านเมื่อ repo เป็น public · D04 ตรวจป้าย issue ว่ามีครบทุกชื่อ
  • ระบบดูแค่ว่ามีไฟล์ ไม่ได้ตรวจเนื้อหา อาจารย์ตรวจเนื้อหาและให้คะแนนแยก
