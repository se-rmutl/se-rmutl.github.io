Case X Mini v1.0 (ครั้งที่ 4)

รุ่นแก้ข้อบกพร่อง · ครั้งที่ 4 ไม่ได้สอน ใช้ศึกษาเพิ่มเติมได้

วิธีรัน

ต้องมี Node.js 18 ขึ้นไป แตก zip แล้วเปิดสองหน้าต่าง

cd v0.9/backend
npm install
npm start            # API http://localhost:3001

cd v0.9/frontend
npm install
npm run dev          # หน้าจอ http://localhost:5173

# ครั้งที่ 3 รันชุดทดสอบ
cd v0.9/backend && npm test
cd v0.9/frontend && npx playwright install chromium && npm run test:e2e

ผู้ใช้ทดสอบ: test_organizer_01 ผู้จัด · test_room_owner_01 เจ้าของห้อง · test_equipment_owner_01 เจ้าของอุปกรณ์ · ดูไฟล์ README ใน zip
