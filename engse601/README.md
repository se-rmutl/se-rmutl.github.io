# พอร์ทัล ENGSE601 · วิธีขึ้น GitHub Pages และเปิดเอกสารทีละครั้ง

## โครงสร้าง

```
index.html            หน้าเดิม เพิ่มส่วน "4 ครั้งสุดท้าย" ไว้เหนือแผน 17 สัปดาห์
config.js             ไฟล์ตั้งค่าเดียว เปิดหรือปิดเอกสาร และกำหนดส่ง
assets/portal.js      อ่าน config.js แล้วซ่อนลิงก์ที่ยังไม่เปิด
sessions/s1–s4.html   หน้าของแต่ละครั้ง
resources/            แอปสาธิต · เล่มและ Pack · สอบปลายภาค
materials/            ไฟล์เอกสาร แยกโฟลเดอร์ตามครั้ง
pre-test/  images/    ของเดิม
```

## ขึ้น GitHub Pages

1. สร้าง repository เช่น `engse601` แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้
2. Settings → Pages → Source: Deploy from a branch → `main` / root
3. เปิดที่ `https://<ชื่อผู้ใช้>.github.io/engse601/`

ลิงก์ทั้งหมดเป็นแบบสัมพัทธ์ ย้ายไปเซิร์ฟเวอร์อื่นได้โดยไม่ต้องแก้

## เปิดทีละครั้ง

แก้ `config.js` เปลี่ยน `false` เป็น `true` แล้ว commit ลำดับที่แนะนำ

| เมื่อไร | เปลี่ยน |
|---|---|
| เริ่มครั้งที่ 1 | `current: 's1'` · `s1` `casex` `roadmap` `exam` = true |
| เริ่มครั้งที่ 2 | `current: 's2'` · `s2` `app_s2` = true |
| เริ่มครั้งที่ 3 (หลังส่งใบงาน 2) | `current: 's3'` · `s3` `app_s3` = true |
| เริ่มครั้งที่ 4 | `current: 's4'` · `s4` `thesis` = true |
| หลังครั้งที่ 4 | `app_v10` = true · `current: ''` |

**ข้อจำกัดของ GitHub Pages:** config.js ซ่อนได้แค่ลิงก์ ไฟล์ที่อยู่ใน repository แล้วเปิดตรงได้ถ้ารู้ URL
ถ้าต้องการกันจริง ให้อัปโหลดโฟลเดอร์ของครั้งนั้นเมื่อถึงเวลาเปิด โดยเฉพาะ

- `materials/s3/` และ `materials/app/CaseXMini_v0.9_Student_S3.zip` มีตารางกรณีทดสอบที่เป็นคำตอบของใบงานครั้งที่ 2
- `materials/thesis/` มีตัวอย่างที่เป็นคำตอบของใบงานครั้งที่ 2
- `materials/app/CaseXMini_v1.0_Student_S4.zip` เผยวิธีแก้ข้อบกพร่อง

## ไม่มีเฉลยในโฟลเดอร์นี้

ไม่มีไฟล์เฉลยใบงาน ข้อสอบ เฉลยข้อสอบ รายการข้อบกพร่องที่ฝังไว้ หรือสคริปต์เดโมของผู้สอน
ไฟล์เหล่านี้อยู่ในชุดผู้สอนเท่านั้น ห้ามเพิ่มเข้ามาใน repository นี้
