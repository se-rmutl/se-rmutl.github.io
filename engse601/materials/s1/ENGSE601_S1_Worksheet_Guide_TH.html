(ข) ถ้าคำสั่งข้ามหน้าจอ จะเกิดอะไร 3 คะแนน

ได้เต็มเพราะบอกทางที่ข้าม บอกผลที่เกิดขึ้นจริง และอ้างกฎที่ถูกละเมิด

(ค) ควรตรวจที่ใดแทน เพราะอะไร 3 คะแนน

“ควรให้ C-03 บริการคำขอตรวจก่อนบันทึก เพราะทุกคำขอไม่ว่ามาทางไหนต้องผ่าน C-03 ส่วน C-01 ยังปิดปุ่มต่อไปได้เพื่อช่วยผู้ใช้ และเมื่อย้ายแล้ว ทดสอบกฎนี้ได้ด้วยการเรียก API ตรงในระดับ Integration”

ได้เต็มเพราะบอกส่วนประกอบ บอกเหตุผลเรื่องทุกทางต้องผ่าน และไม่ได้เสนอให้ลบการตรวจที่หน้าจอทิ้ง
